# Source package

Folder `src/` menggunakan source layout agar import development tidak keliru mengambil working directory sebagai installed package.

| Path | Fungsi |
|---|---|
| `opticargo_agents/` | Package internal service: API, contracts, workflow, nodes, clients, integrations, security, health, and observability. |

Semua file implementation masih kosong. Penjelasan rinci tersedia pada [`opticargo_agents/README.md`](opticargo_agents/README.md) dan README setiap subpackage.
